# 事务助手(个人事务管理工具)

以 **AI 通知分析为入口**,集成桌宠、工作台、日历、待办与提醒的 Windows 桌面应用。

> 把杂乱信息转化为可确认、可安排事项的个人助手:拖入群通知/文件 → AI 综合分析 → 查看重点与候选安排 → 确认后加入日历/待办 → 到时提醒。

## 核心特性(首版)

| 模块 | 说明 |
| --- | --- |
| 桌宠入口 | 悬浮常驻、可拖动;把通知文本或文件**拖给桌宠即开始 AI 分析**;右键菜单(分析剪贴板/新建日程/新建待办/今日面板/工作台);进度与提醒轻提示气泡 |
| 工作台 | 通用 AI 聊天 + 通知分析双入口;多消息、多附件;流式回复;历史会话;补充材料生成**新版本分析**;候选事项卡片(加入/修改/暂不处理) |
| 桌面信息面板 | 今日课程、日程、到期待办、校历;可固定、按需呼出 |
| 日历与待办 | 月视图日历(课程与日程同屏、颜色区分);待办分组(逾期/今天/未来);**截止时间与执行时段分离**,待办可关联执行日程 |
| 课表/校历导入 | 拖入课表或校历 → AI 提取 → 预览纠正(缺失开学日期必须补填)→ 确认导入;支持每周/单双周/指定周次;临时停课调课 |
| 个人画像 | 明确资料直接生效;聊天中推测的偏好以"建议"形式给出,采纳后才生效,可删除 |
| 模型服务 | 自行配置多个 OpenAI 兼容 / Responses 协议服务商;默认模型失败自动切换备用模型并弹泡提示;支持多模态;连接测试、自动获取模型列表;API Key 用系统安全存储加密 |
| 数据 | 全部本地保存(SQLite);手动备份导出/恢复;提醒独立于 AI 运行 |

## 技术栈

- **Electron + React + TypeScript**(electron-vite 构建)
- **SQLite**(sql.js / WASM,免原生编译,统一本地朴素时间存储)
- 多窗口架构:工作台主窗口 / 透明桌宠窗口 / 信息面板窗口,共用主进程服务

## 快速开始

```bash
npm install            # 安装依赖
npm run dev            # 开发模式启动
npm test               # 单元测试(37 例,覆盖计划中的关键规则)
npm run build          # 构建到 out/
npm run dist           # 打包 Windows 安装包(dist/,需本机可运行 electron-builder)
```

> 如果 npm 拦截了 Electron 的下载脚本(提示 `Electron failed to install correctly`),执行:
> `node node_modules/electron/install.js`

## 首次使用

1. **设置 → 模型服务**:添加你的模型 API(接口地址 + API Key + 默认模型),点"测试连接"确认可用。
2. (可选)**画像**:填写身份、作息等基本资料,让分析与安排选项更贴合你。
3. (可选)**课表**:设置学期开学日期(第一教学周周一),拖入课表图片一键导入。
4. 之后把任意群通知文本/文件**拖给桌宠**,即可体验完整流程。

## 设计要点(与计划细则对应)

- **分析结果与正式事项分开**:AI 只产出候选草稿;用户确认才写入日历/待办;重复确认不产生重复事项(指纹去重)。
- **材料逐步到齐**:同一会话可继续补充材料,产生新版本分析,旧结果不会被覆盖。
- **截止 ≠ 执行**:"周五前提交"是待办的截止;"周四下午准备"是关联的执行日程,移动执行不改变截止。
- **提醒独立于 AI**:模型全部不可用时,本地提醒照常工作;重启后补报错过的提醒。
- **改期不擅自生效**:变更在分析结果中单独列出,由用户确认更新。
