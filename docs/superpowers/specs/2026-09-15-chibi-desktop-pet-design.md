# Q 版坐姿桌宠：形象与轻量接入设计

日期：2026-09-15。状态：用户已确认基础效果图，并要求充分细化规划；功能未实施。本文区分已确认的美术方向与实施计划提出的工程默认值，不把出图完成等同于桌宠接入完成。

## 1. 已确认方向

- 参考 DeepSeek Balance Whale Widget 的角色陪伴感和按压弹性，不引入余额统计、DSH 插件或其整套资源管理。
- 采用温柔陪伴型 Q 版人物。用户提供角色图后，明确选择以该角色本身为基础，而不是仅借鉴风格另创人物。
- 保留蓝紫渐变短发、粉紫半睁眼、金色双环发饰、紫色垂带、淡腮红和慵懒神情。
- 大头小身体的坐姿小团子：双腿收拢，小手放在膝前；延续原图白色、深色、淡紫服装元素，补全裙装。
- 下半身是本次设计补全，不宣称是角色的官方设定。
- 用户已认可生成的静态效果图。首版使用该单张透明 PNG，人物和气泡分离，动画由本机 CSS 完成。
- 下一步规划为替换小熊、保留拖动/右键/今日要点/材料拖入/提醒，并加入呼吸、按压回弹、忙碌轻晃及短暂提醒动作。

本轮不包含：多表情素材、眨眼或嘴型帧、Live2D、骨骼、走动、养成、语音、音效、换装、角色上传、屏幕吸附/镜像、余额统计、自动调用 AI 生成人物或台词。参考项目的所有功能不自动进入本项目范围。

## 3. 模块分区和并行开发

桌宠作为独立功能区 P，与邮箱 A/B/C/D 并行，不并入邮箱 UI 区。

| 区域 | 职责和文件 | 协作边界 |
| --- | --- | --- |
| P-V 视觉 | pet/assets、PetCharacter、PetBubbles、pet.css | 只接收展示状态，不接数据库/模型 |
| P-I 交互与事件 | pet/contracts、model、gesture、controller、pet.tsx、pet-main.tsx | 通过注入式 API/事件与主进程交互 |
| P-N 原生辅助 | 新增 main/pet/drag、activity、geometry | 提供可测试的辅助服务，不直接编辑中央 IPC |
| R 统一集成 | main/windows、ipc、index，shared/api、shared/pet，preload/index，依赖/测试配置 | 与邮箱共用同一负责人；串行合入接线 |
| C 引擎所有者 | main/services/engine.ts 的生命周期通知接缝 | 与邮箱 C 同一所有者；桌宠不另开分支同时修改引擎 |

`tests/pet/` 和 `tests/ui/pet/` 归桌宠。邮箱 D 的 `tests/ui/` 所有权不包括 `tests/ui/pet/`，公共测试配置仍归 P0/R。不改共享 `src/renderer/shared/ui.css`，只在 pet 专用 CSS 中覆盖透明背景，避免污染工作台。

桌宠不依赖邮箱 schema 或收件同步完成；仅依赖最小共用测试环境和冻结契约。邮箱后续通过既有气泡桥发送汇总提醒，不能导入人物组件、控制人物 DOM 或修改角色图片。忙碌状态按实际分析任务决定，普通邮箱同步/阅读不得假装正在 AI 分析。

## 4. 视觉和尺寸默认值

以下为本计划建议的首版工程参数，真机若需调整，作为一个集中配置提交更新，不分散写常量。

| 项目 | 默认值 |
| --- | --- |
| 窗口 | 320 × 400 DIP，透明、无边框、置顶、不显示任务栏 |
| 角色图框 | 200 × 200 CSS px，object-fit: contain，完整图片不裁切 |
| 上/下留白 | 12 / 8 px |
| 气泡区域 | 高 180 px，宽不超过 288 px，独立于人物动画 |
| 可见气泡 | 最多 3 条，间隔 6 px；每条最多 2 行，长内容省略 |
| 正文提示 | 默认 5 秒，分析结果 6 秒，提醒/错误 8 秒 |
| 点击/拖动阈值 | 屏幕坐标位移的欧氏距离达到 6 px 开始拖动 |

布局用固定气泡区域避免出现/消失时人物上下跳位。保留完整文本作为可访问标签及 title；屏幕气泡不是通知档案，超量移除最早提示，不删除实际业务通知或事项。

首版不实现像素级穿透。透明区域不等于鼠标自动穿透，原生窗口仍有矩形命中区域；应在真机核验是否明显阻挡桌面操作，若不可接受，单独设计穿透方案而不是直接禁用整个窗口鼠标事件。

## 5. 动画和状态

外层负责状态运动，内层负责按压形变，图像本身不承担重复的 transform。气泡不随人物摇晃、缩放或翻转。

| 情况 | 表现 | 结束规则 |
| --- | --- | --- |
| 待机 | 3.6 秒循环，向上最多 3 px | 隐藏、拖动或减少动态效果时暂停 |
| 按住 | 底部为轴，scaleX(1.04)/scaleY(0.96)，约 100 ms | 松开后 320 ms 回弹；取消不触发点击 |
| 拖动 | 人物稳定跟随，无呼吸/轻晃；恢复正常比例 | 释放/失焦/取消时停止原生轮询 |
| 分析中 | 1.8 秒循环，左右最多 2 度 | 所有相关活动结束后停止，不由气泡超时控制 |
| 提醒 | 向上最多 6 px，600 ms 一次；不持续跳动 | 提醒标识保持到期，再显示仍在运行的忙碌状态 |
| 减少动态效果 | 禁用浮动、轻晃、跳跃和回弹位移 | 保留静态状态文案、焦点和按下描边 |

业务状态和临时提醒分开保存：拖动 > 提醒 > 忙碌 > 待机。提醒到期只清除提醒，不清除正在运行的分析。按压是独立输入反馈，不把业务状态改成 idle。

不把 `evt:materials-accepted` 当作“分析开始”：当前引擎在自动分析结束后才广播该事件。也不把任意 `evt:analysis-updated` 当成功：失败结果同样会更新。计划补充最小的带任务 ID 活动通知，由实际执行入口发出开始和终态，既有业务事件顺序不改。

## 6. 输入及旧功能回归

- 鼠标左键按下仅记录位置和显示按压反馈；超过阈值才请求原生拖动。未超过阈值的释放查询今日要点，不调用模型。
- 使用 Pointer Capture 接收移出图框后的释放；pointercancel、lostpointercapture、窗口失焦、隐藏和组件卸载均可幂等停止拖动。异步 start/end 串行，不能出现 end 先到后又 start 的泄漏。
- Enter/Space 触发同一个今日要点操作；右键仍开原菜单；Shift+F10 可访问菜单。键盘 click 与 pointerup 不能重复请求。
- 角色图片 draggable=false，不触发浏览器原生拖图。外部文件/文本拖入保持既有 addMaterials 流程，原有“拖入即分析”不变，不与鼠标拖动桌宠混淆。
- 今日要点、拖动、右键 API 拒绝时显示有限错误提示，不制造未处理 Promise；组件卸载后忽略迟到数据。
- 人物加载失败只回退到旧 SVG 小熊，保持交互可用；不请求网络素材，不触发递归失败循环。回退不作为新形象验收通过。

## 7. 主进程和运行时边界

扩大窗口后，位置恢复必须使用目标显示器的 workArea，包括负坐标、任务栏占用和 DPI。旧 pet:x/pet:y 保留键名并做数值校验；没有可用交集的旧位置回主屏工作区内。相邻信息面板按新桌宠实际边界定位，不再写死 +160。

透明设置还必须覆盖当前公共 CSS 的 html/body/#root 背景。开发用 loadURL，打包后的本地页面用 loadFile；这部分在 windows.ts 中统一处理并回归工作台、面板，防止只修桌宠却留下共用加载错误。

新增状态快照和拖动通道由 R 校验发送者为桌宠窗口的主 frame；保留 contextIsolation=true、nodeIntegration=false 和现有安全策略，不为图像或拖动开启 Node。任务活动仅保存内存状态，不新增数据库迁移、不导出到备份。

运行时 PNG 和 CSS 不访问生成工具、原始参考路径或参考仓库，不增加 AI 调用或外部遥测。不同开发工作区不能共用真实 userData；隔离能力未落地前同时只运行一个 Electron 实例。

## 8. 验收与状态

1. 图像身份和服装按用户确认图保持；浅/深背景均无白底、黑底或明显边缘光圈。
2. 动画不移动气泡、不互相覆盖、不切掉头发/脚；减少动态效果生效。
3. 连续点击、越界释放、快速开始/结束、失焦、隐藏/重开均无跟鼠标失控或残留轮询。
4. 分析失败不显示成功；两个任务重叠时一个结束不提前待机；提醒结束恢复仍忙碌状态。
5. 今日要点、右键菜单、材料拖入、课程/日程/待办提醒、托盘显示隐藏保持可用。
6. 原有与新增测试、类型检查、构建通过；解包运行无本地路径引用或图片缺失。
7. Windows 100%/125%/150%/200% 缩放、双屏/负坐标/断开副屏分别记录实测，不把 jsdom 通过等同于原生验收。
8. 公开发布前完成素材授权核验，否则保留“公开分发未批准”的状态。
