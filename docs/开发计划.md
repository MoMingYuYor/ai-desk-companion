# 开发计划与实施记录

> 对应 ChatGPT 计划中的"5 个阶段、10 个开发任务"。下表为初版(0.1.0)的落实情况。

> 2026-09-15 增补：初版记录保留；多邮箱联动的阶段 F—I 和桌宠迭代阶段 J 均尚未实施。桌宠基础效果图已获用户认可，工程接入已细化为计划。历史测试记录不代表当前环境已重新验证，进入实施后需先安装依赖并建立基线。

## 阶段 A:本地基础

### ① 桌宠、窗口和托盘骨架 ✅

- 桌宠:透明无边框窗口,常驻置顶(screen-saver 级),可拖动(主进程轮询光标),位置持久化。
- 托盘:打开工作台 / 显示隐藏桌宠 / 今日面板 / 退出;主窗口关闭隐藏到托盘,真正退出走托盘菜单。
- 单实例锁防止重复启动。

### ② 日历、待办及关联关系 ✅

- SQLite 建模:events / todos(+ linked_event_id 关联执行时段)/ fingerprint 去重。
- 月视图日历:课程与日程同屏;日详情;手动新建/编辑/删除。
- 待办:分组(逾期/今天/未来/无截止/已完成)、优先级、关联执行时段(调整执行不改截止)。

### ③ 提醒与今日面板 ✅

- 提醒服务独立于 AI:30 秒轮询 + `fired_reminders` 防重复;睡眠恢复(`powerMonitor`)立即扫描;重启后补报 24h 内错过的提醒。
- 信息面板:今日课程/日程/到期待办/校历,固定开关,60 秒自动刷新。

## 阶段 B:对话工作台

### ④ 模型配置与自动切换 ✅

- 服务商 CRUD、协议(OpenAI 兼容 / Responses)、多模态标记、连接测试、`/models` 自动获取、默认/备用顺序。
- 故障切换:网络错误与 429/5xx 有限重试(每服务商 2 次)→ 按备用顺序切换 → 桌宠气泡提示;4xx 鉴权错误不重试直接切换;全部失败保留材料;用户取消(AbortController)后不再发起任何请求。

### ⑤ 会话与流式聊天 ✅

- SSE 流式渲染、停止、重试;历史会话管理;材料作为上下文附件进入对话。
- 聊天中识别 `[PROFILE]` 标记生成画像建议(pending,需用户采纳)。

## 阶段 C:通知分析

### ⑥ 统一材料接收与解析 ✅

- 桌宠拖拽 / 剪贴板 / 工作台粘贴与文件选择,四路统一进入"材料集合"。
- 解析:txt/md 等文本、图片(多模态直传)、PDF(尽力提取文本,失败明确提示)。
- 补充材料生成新版本分析(version 单调递增,不覆盖)。

### ⑦ 分析结果与确认操作 ✅

- 结构化输出(严格 JSON 提示词 + 容错解析):摘要、要点、待确认、冲突、变更、候选事项。
- 候选卡片:加入(确认才落库)/ 修改 / 自行填写 / 暂不处理(进待处理列表)。
- 指纹去重:重复确认不产生重复事项。

## 阶段 D:学生场景 / 个人辅助

### ⑧ 课表、校历导入 ✅

- 统一导入向导:拖文件或粘贴 → 模型提取 → 预览纠正(开学日期缺失必须补填才能确认)→ 确认导入(重复课程跳过)。
- 教学周映射:周次区间(单双周/指定周次)→ 具体日期;跨年正确;临时停课/调课仅影响当次。

### ⑨ 个人画像与安排选项 ✅

- 画像三类:基本资料 / 作息习惯 / 偏好;明确资料直接生效,建议需采纳。
- 分析与聊天上下文自动注入:个人资料 + 近 8 天日程 + 当周课程与校历要点。

## 提取契约层与三级自愈（2026-09-17 完成）

解决"接入不同能力 AI 模型时，提取流程不统一"的问题。设计见 [提取契约层设计](superpowers/specs/2026-09-17-extraction-contract-design.md)。

- **单一事实源 schema**：`src/shared/extraction.ts` 定义分析输出字段（时间/地点/事件/参与人物/置信度等），系统提示词规范与运行时校验器由同一份 schema 生成，不再两处维护。
- **三级自愈**（通知分析路径）：解析+校验失败 → 同模型携带错误反馈自修复一次 → 仍失败按备用顺序切换下一个模型（气泡提示"输出格式不合格"）→ 全部耗尽才 failed 并保留各模型失败摘要。
- **字段降级不报废**：类型不符的字段置空并写入 `questions` 让用户可见；新增 `participants` 参与人物提取，确认落库并入备注。
- **能力开关**：`supportsJsonMode`（设置页勾选，schema v3 迁移），开启后 chat-completions 请求注入 `response_format: json_object`；所有模型统一附加 few-shot 修正示例。
- 测试：新增 17 例（校验矩阵/自愈回路/切换游标/response_format/participants 落库/迁移 v3），全量 231 例通过。

### 邮箱细则中的固定参数

| 项目 | 值/规则 |
| --- | --- |
| 邮箱范围 | 首版仅 INBOX；无 SMTP 发送/回复 |
| 首次与历史 | 最近 30 天；单账号每次向前 30 天 |
| 自动同步 | 每 5 分钟，启动/唤醒检查到期任务 |
| 分页/批次 | 列表 50、同步 50 |
| 并发 | 两个账号，同账号互斥 |
| 超时/退避 | 30 秒超时；30 秒 → 1 分钟 → 2 分钟 → 5 分钟 |
| 限额 | 正文 5 MiB、单附件 20 MiB、一次分析附件合计 20 MiB |
| 已读 | 本地状态，不写回服务器 |
| AI | 手动触发；材料按版本固定；确认才保存正式事项 |
| 备份 | 排除邮箱配置/凭据/收件缓存；保留已分析文本和来源；不打包附件字节 |
