# 三到五分钟演示脚本

演示使用独立 userData、合成输入和实际验收构建。录制前确认模型凭据与发送范围；没有可用模型时只展示已生成的离线工程产物，并在画面标注。本文是录制脚本，视频尚未录制，不能当作已播放的演示证据。

开始约 30 秒介绍材料分散的问题，打开工作台和待办，输入“准备实习面试”。创建并编辑待办，说明本地存储与重启保留。

接下来约 60 秒展示 Ops。用需要补时间的输入进入澄清，填写答案；再展示一份读后修改提案，解释实际目标、冻结参数与影响，先拒绝检查零写入，再另发运行批准一次。需要等待模型的部分可剪辑，但必须在画面注明，重复点击结果如实保留。

Research 用约 60 秒展示合成中文和 emoji 资料，打开结论的引用并显示准确高亮，再展示冲突双方或证据不足。解释 record_scope 和 all_of，未支持结论不进入事实区。截图只反映页面状态，不能替代引用和数据库验证。

Eval 用约 60 秒展示冻结配置、Ops/Research 两数据的离线结果、某一失败路径的 trace 和回放。说明固定路由与实际请求次数，标注 fake 流程验证，不展示未经人工审阅的真实成绩。

最后约 30 秒说明已经验证的工程边界、真实实验与真人验收的剩余事项，并打开 README 的复现步骤。录制文件、构建 SHA、日期、发送范围和素材 hash 随验收登记；公开上传另行决定。
